# Weather Checker

Учебное приложение для просмотра погоды по выбранному городу с микросервисной архитектурой.

# Стек
Kotlin, JVM 21, Spring Boot 4.1.1, Maven Wrapper.

## Функциональность MVP

Пользователь сможет выбрать город и посмотреть погоду на той же странице.

Будут отображаться:

- температура воздуха в градусах Цельсия;
- направление ветра в градусах;
- скорость ветра в м/с;
- влажность воздуха в процентах;
- облачность в виде описания;
- текущее погодное явление словами;
- прогноз суммы осадков в мм за полный текущий календарный день по местному времени выбранного города;
- дата и время погодных данных источника с указанием смещения часового пояса;

Контракт API описан в [docs/weather-api.md](docs/weather-api.md).

## Архитектура

Приложение будет состоять из двух сервисов:

- **WeatherService** — принимает запрос от фронтенда, вызывает WeatherLoaderService через gRPC и возвращает фронтенду JSON с погодой.
- **WeatherLoaderService** — получает данные из внешнего погодного API и возвращает их в WeatherService.

Фронтенд будет обращаться к WeatherService по HTTP. Между двумя сервисами планируется взаимодействие через gRPC.

## Текущее состояние

Созданы каркасы двух Spring Boot приложений. Получение погоды, взаимодействие через gRPC и фронтенд пока не реализованы.

## Сборка и проверка

Требуется JDK 21. Для сборки используется Maven Wrapper.

Команды ниже предназначены для Git Bash. Проверка начинается из корня репозитория.

Сборка и запуск тестов WeatherService:

```bash
cd weather-service
./mvnw verify
```

После завершения — переход в соседний проект и проверка WeatherLoaderService:

```bash
cd ../weather-loader-service
./mvnw verify
```

Ожидаемый результат каждой проверки — `BUILD SUCCESS`.
