# Weather API provider

## Provider

Open-Meteo
- поддерживает данные, необходимые для нашего API-контракта;
- имеет бесплатный тариф, достаточный для запуска MVP;
- бесплатный некоммерческий API не требует API key.

## Geocoding API

https://geocoding-api.open-meteo.com/v1/search

- `name` — название города, обязательный параметр поиска.
- `latitude` — широта местоположения.
- `longitude` — долгота местоположения.
- `timezone` — часовой пояс местоположения.
- `country` — страна.
- `admin1` — административный регион первого уровня, к которому относится местоположение.

## Forecast API

https://api.open-meteo.com/v1/forecast

Для верхнеуровнего запроса возможно запросить 6 полей:

- `latitude` — широта местоположения;
- `longitude` — долгота местоположения;
- `current` — текущие погодные данные, содержащие:
    - `temperature_2m` — текущая температура воздуха;
    - `relative_humidity_2m` — относительная влажность воздуха;
    - `cloud_cover` — облачность;
    - `wind_speed_10m` — скорость ветра;
    - `wind_direction_10m` — направление ветра;
    - `weather_code` — WMO-код текущего состояния погоды, используемый для получения текстового описания погоды;
- `hourly` — почасовые погодные данные, содержащие:
    - `precipitation` — количество осадков за час;
- `timezone` — часовой пояс, используемый для получения времени относительно местоположения;
- `wind_speed_unit` — единица измерения скорости ветра.

## Timezone

Для определения локального времени выбранного города используется `timezone=auto`.
Временная зона определяется Open-Meteo автоматически по координатам.

## Precipitation

Количество осадков получается через `hourly=precipitation`.
Значения суммируются по часовым интервалам текущих суток.
Расчёт выполняется с почасовой точностью.

## Limits

- API key для бесплатного некоммерческого API не требуется;
- до 600 запросов в минуту;
- до 5 000 запросов в час;
- до 10 000 запросов в день;
- бесплатный API предназначен для некоммерческого использования;
- SLA отсутствует;
- требуется атрибуция Open-Meteo.
