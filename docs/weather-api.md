## Запрос

GET /api/v1/weather/current?latitude=54.70639&longitude=20.51102

Допустимый диапазон координат:
- latitude — широта: от −90 до 90 включительно;
- longitude — долгота: от −180 до 180 включительно;

Оба параметра обязательны, допускают дробные значения и ноль.
Значения NaN и бесконечность также недопустимы.
Перед запросом погоды пользователь выбирает город из результатов поиска.
Каждый вариант содержит название города, регион, страну, широту и долготу.
Погода запрашивается для выбранного места.


Ответы:
- 400 Bad Request — отсутствие любого параметра, нечисловое значение или выход за диапазон.
- 503 Service Unavailable — временно не можем предоставить данные из-за недоступности внешнего сервиса.
- 504 Gateway Timeout — не удалось получить ответ от внешнего погодного API за установленное время ожидания.

## Поиск города

GET /api/v1/cities?query=Калининград

Пример ответа:
```
[
    {
        "name": "Калининград",
        "region": "Калининградская область",
        "country": "Россия",
        "latitude": 54.70639,
        "longitude": 20.51102
    }
]
```

Параметр query обязателен. Перед поиском удаляются пробелы
в начале и конце строки.

Ответы:
- 200 OK — список найденных мест.
- 200 OK с пустым списком [] — совпадений нет.
- 400 Bad Request — query отсутствует или пуст после удаления пробелов.
- 503 Service Unavailable — временно не можем предоставить данные из-за недоступности внешнего сервиса.
- 504 Gateway Timeout — не удалось получить ответ от внешнего погодного API за установленное время ожидания.

## Успешный ответ текущей погоды

Пример JSON:
```
{
    "temperatureInCelsius": 22.4,
    "windDirectionInDegrees": 234,
    "windMetersPerSecond": 18,
    "humidityInPercent": 40,
    "cloudiness": "облачно",
    "precipitationInMillimeters": 30,
    "weatherCondition": "дождь",
    "observedAt": "2026-10-03T20:45:00+02:00"
}
```

Описание:
- temperatureInCelsius: температура в градусах Цельсия, передает значение в виде дробное значение типа 'Double';
- windDirectionInDegrees: направление ветра , передает значение в виде целочисленного типа 'Integer';
- windMetersPerSecond: скорость ветра в метрах в секунду, передает значение в виде целочисленного типа 'Integer';
- humidityInPercent: влажность окружающей среды в процентах, передает значение в виде целочисленного типа 'Integer';
- cloudiness: облачность, содержит константы (облачно, ясно, переменная облачность, пасмурно),
передает значение в виде строкового типа 'String';
- precipitationInMillimeters: количество осадков за сутки начиная с 00.00 до 00.00 по местному времени в миллиметрах,
передает значение в виде целочисленного типа 'Integer';
- weatherCondition: текущее погодное явление, содержит константы(дождь, снег, град, без осадков, туман),
передает значение в виде строкового типа 'String';
- observedAt: время текущих погодных данных из источника, передает значение в виде типа 'OffsetDateTime';


Ответы:
- 200 ОК - ответ в виде JSON содержащий основную информацию по погоде

Правила:
- Округление скорости и осадков через Math.round;
- Осадки — прогноз суммы за текущий день с 00:00 до следующих 00:00 по времени города.

## Формат возвращаемых ошибок

Пример возвращаемого тела ошибки 504 Gateway Timeout:
```
{
    "code": "WEATHER_PROVIDER_TIMEOUT",
    "message": "Время ожидания ответа превышено. Попробуйте ещё раз."
}
```

Пример возвращаемого тела ошибки 400 Bad Request:
```
{
    "code": "INVALID_USER_REQUEST",
    "message": "Нарушен допустимый диапазон координат, разрешенный диапазон координат составляет: latitude — широта: от −90 до 90 включительно"
}
```

Пример возвращаемого тела ошибки 503 Service Unavailable:

```
{
    "code": "WEATHER_PROVIDER_UNAVAILABLE",
    "message": "Временно не можем предоставить данные из-за недоступности внешнего сервиса."
}
```
